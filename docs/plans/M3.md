# M3 — Cloud brains and policy

Goal: Claude, OpenAI, and Gemini behind one provider trait, gated by deterministic policy.

- Providers with streaming, tool calling, vision, timeouts, retries, token/cost accounting.
- API keys in the OS keystore via `autopilotd keys set claude|openai|gemini`.
- Router rules: high sensitivity stays local unless allowed; offline → local; low confidence /
  long generation / vision → cloud; preferred provider with fallback order.
- Redaction layer before every cloud call; tool output marked untrusted.
- Property tests for the router; tests proving high-sensitivity content never reaches a provider stub.

Acceptance: high-sensitivity content is never sent to the cloud in tests; cost shown per task.
