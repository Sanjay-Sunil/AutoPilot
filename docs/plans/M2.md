# M2 — Agent loop

Goal: useful local-first agent with approvals, kill switch, and audit.

- Rules fast path → Laya (`laya-serve`, `POST /v1/systemone`) → deterministic router.
- Laya lifecycle: spawn on first use from `~/.local/share/autopilot/laya-venv`, unload after 5 min idle.
- System tools: files in shared roots, shell allowlist, open apps, clipboard, system info,
  Hyprland window control (`hyprctl`).
- `task.update` with per-step brain badge; `approval.request`/`response` with expiry; kill switch
  (phone, tray, hotkey, CLI); hash-chained audit log.

Acceptance: "list the files in Documents and summarize the newest one" runs locally with correct
approvals; kill during a task stops it within 200 ms.
