# M0 — Foundations

Goal: monorepo that builds, protocol types shared with the phone, CI green, backend stack runnable.

- Cargo workspace (`crates/*`, `services/backend`); `apps/desktop/src-tauri` built separately.
- `agent-protocol`: envelope + message types, ts-rs bindings into `apps/mobile/src/protocol/`.
- Crate API contracts (transport, core, llm, capture, input, files, audit, browser).
- `services/backend`: blind relay + `/health` (no DB required). Postgres migrations for the registry.
- `services/infra`: compose with Postgres 17, backend, Caddy (TLS), coturn (profile `turn`).
- CI: fmt, clippy `-D warnings`, tests on ubuntu + windows; mobile typecheck/lint/test; backend image.
- Docs: architecture, threat model, decisions, runbook.

Acceptance: `cargo test --workspace` and CI green; `docker compose config` valid.
