# M1 — Pair and connect

Goal: phone pairs via QR and exchanges `ping`/`pong` over Noise XX, both directly and via the relay.

- `agent-transport`: device keys (0600 file, keyring later), trust store, pairing tokens, Noise XX
  responder, WS server on `:7878`, relay client (`?role=laptop`, waits for `peer-connected`).
- `autopilotd pair [--json]` and control socket `{"cmd":"pair"}` → `{uri, code, expires_at_ms}`.
- Phone: QR scan, pin `laptop_pk`, Noise initiator (`@noble/*`), `pair.claim`, confirmation code.
- Tray app shows the QR and device list.
- Tests: Rust test client against daemon (direct + through an in-process relay); wrong pinned key
  aborts; unknown key without claim is dropped; replayed `seq` closes.

Acceptance: ping/pong from a phone on mobile data to a laptop on home Wi-Fi via the relay.
(Owner decision: Noise-over-WS replaces the spec's WebRTC for M1; TURN not needed yet.)
