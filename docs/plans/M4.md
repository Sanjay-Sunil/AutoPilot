# M4 — Screen and files

Goal: on-demand screen view and verified file transfer both ways.

- Capture: Hyprland `grim -t jpeg` (first-class), X11 xcap, Windows WGC. JPEG 1280 px, q60.
- `screen.request` snapshot/start/stop; 2 fps default (cap 15); split into ≤ 64 KB `screen.frame`
  parts; desktop notification while streaming; stops on kill/session loss.
- Files: chunked 64 KB transfer with SHA-256, resume, progress; inbox for phone→laptop; approval
  for large/executable files; traversal and symlink-escape tests.

Acceptance: snapshot < 250 ms on LAN; streaming usable over relay; 1 GB file verifies and resumes.
(Owner decision: JPEG frames instead of an H.264 video track; WebRTC video is a later upgrade.)
